# The pyright releases install_pyright installs with verify_checksums: strict,
# newest first, each as a requirements file that pins pyright and every
# dependency to one version with the SHA-256 of each wheel the orb can install
# (CPython 3.11 to 3.14 on Linux x86_64 and aarch64, glibc or musl). uv
# installs a block with --require-hashes, so a file whose hash isn't listed, or
# a package the block doesn't pin, fails the install before anything runs.
# The lock holds pyright[nodejs], so Node.js comes as a wheel (nodejs-wheel-binaries, which
# needs glibc 2.28 or musl) and pyright never downloads Node.js or npm packages when it runs.
#
# Add a release with:
#   src/install/lock.sh -t pyright -v <version>
# and paste its output at the top.
